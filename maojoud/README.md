# موجود — Maojoud

منصة لبيع وشراء السلع المستعملة والجديدة في السوق السعودي، مبنية بـ Next.js 16 و Base UI و Prisma.
المنصة تستقبل المدفوعات عبر **مُيسر** وترسل رمز التحقق للجوال عبر **Authentica**.

## التشغيل محليًا

```bash
cd maojoud
npm install
cp .env.example .env          # ثم عدّل القيم
npm run setup                 # إنشاء قاعدة البيانات + الأقسام + حساب المسؤول
npm run dev                   # http://localhost:3000
```

في بيئة التطوير، إذا تُركت مفاتيح Authentica ومُيسر فارغة:
- يظهر رمز التحقق على الشاشة ويُطبع في سجل الخادم بدل إرسال SMS.
- يظهر زر «دفع تجريبي» بدل نموذج الدفع.

هذان البديلان معطلان تمامًا في الإنتاج (`NODE_ENV=production`).

## الصفحات

| المسار | الصفحة |
|---|---|
| `/` | الرئيسية: الشعار، البحث، السلة، «أضف سلعتك»، البانر، الأقسام، المضافة مؤخرًا، «لما تشتري من موجود؟» |
| `/products/[id]` | صفحة السلعة: الصور، الاسم، الوصف، البائع وتقييمه، مراجعات البائع، أيقونات الثقة، «اشترِ الآن» و«أضف للسلة» |
| `/users/[id]` | الملف الشخصي: الاسم والصورة والتقييم والمراجعات والسلع؛ ولصاحب الملف: تعديل البيانات، حذف السلع، تبويب «طلباتي» |
| `/login` | التسجيل/الدخول برقم الجوال ورمز التحقق، ثم إكمال الملف للمستخدم الجديد |
| `/sell` | عرض سلعة: القسم (مع «أخرى»)، الاسم الكامل، الحالة، الوصف (300 حرف)، السعر، الصور مع الترتيب والحذف |
| `/cart` → `/checkout` → `/checkout/pay/[id]` | السلة، اختيار العنوان (محفوظ أو جديد يُحفظ)، اختيار Apple Pay أو مدى/بطاقة، ثم الدفع |
| `/orders/[id]` | تفاصيل الطلب وحالته، وتقييم البائع بعد التوصيل |
| `/<ADMIN_PATH>` | لوحة التحكم (مخفية) |

## لوحة التحكم

- لا يوجد أي رابط لها داخل المنصة. تعمل فقط عبر المسار السري `ADMIN_PATH` في `.env`
  (مثلًا `https://maojoud.sa/control-7f3a9c`)، والمسار الداخلي يعيد 404 إذا طُلب مباشرة.
- الدخول باسم مستخدم وكلمة مرور مشفرة بـ **bcrypt** (cost 12)، مع حد لمحاولات الدخول الخاطئة.
- إنشاء مسؤول جديد أو تغيير كلمة المرور:
  ```bash
  npm run admin:create -- <username> <password>
  ```
- الصفحات: التقارير (المبيعات، التسجيلات، السلع المضافة مع الفرز بالتاريخ)، المستخدمون (تصفح وتعديل)،
  الطلبات (جديد / يتم التوصيل / تم التوصيل مع الفرز بالحالة والتاريخ)، محتوى المنصة (صورة البانر والأقسام).

## الدفع — مُيسر

1. ضع المفاتيح في `.env`: `NEXT_PUBLIC_MOYASAR_PUBLISHABLE_KEY` و `MOYASAR_SECRET_KEY`.
2. من لوحة مُيسر ← Settings ← Webhooks أضف:
   `https://<domain>/api/webhooks/moyasar` مع Secret Token يطابق `MOYASAR_WEBHOOK_SECRET`، وفعّل حدث `payment_paid`.
3. **Apple Pay**: من لوحة مُيسر ← Settings ← Apple Pay Domains نزّل ملف التحقق وضعه في
   `public/.well-known/apple-developer-merchantid-domain-association` ثم اضغط Validate. يلزم HTTPS.

لا يُؤكد أي طلب بناءً على رابط العودة وحده: صفحة العودة والـ webhook يجلبان الدفعة من خادم مُيسر
ويتحققان من الحالة والمبلغ والعملة ورقم الطلب قبل التأكيد. كل سلعة قطعة واحدة، لذلك تُحجز مؤقتًا
(20 دقيقة) عند بدء الدفع حتى لا يدفع مشتريان ثمن السلعة نفسها.

اختبر بالبطاقات التجريبية مع مفاتيح `pk_test_` / `sk_test_` (مثل مدى `4201320111111010`).

## رمز التحقق — Authentica

ضع `AUTHENTICA_API_KEY` من https://portal.authentica.sa/settings/apikeys/ ، واضبط
`AUTHENTICA_TEMPLATE_ID` و `NEXT_PUBLIC_OTP_LENGTH` حسب القالب المستخدم.
الأرقام تُحوّل تلقائيًا إلى الصيغة الدولية `+9665XXXXXXXX`. يوجد حد لإعادة الإرسال (دقيقة) و5 رسائل في الساعة لكل رقم،
و5 محاولات تحقق لكل رمز.

## الصور

كل صورة مرفوعة (سلع، صور شخصية، بانر) تُعالج في الخادم عبر **sharp**: تصحيح الاتجاه، حذف بيانات EXIF
(ومنها الموقع الجغرافي)، تصغير الأبعاد (1600px للسلع) والتحويل إلى WebP بجودة 80، مع نسخة مصغرة 480px
لبطاقات السلع. كما تُصغّر الصور في المتصفح قبل الرفع لتسريعه.
الملفات تُحفظ في `storage/uploads` — في الإنتاج اجعل هذا المجلد على قرص دائم.

## الهوية

- **الشعار**: الملف `public/brand/logo.svg` مؤقت. ضع الشعار الرسمي مكانه، أو ضع ملفك (مثل `logo.png`)
  واضبط `NEXT_PUBLIC_LOGO_URL=/brand/logo.png`. الشعار يُعرض كما هو دون أي إضافة.
- **اللون الأساسي**: درجات الأزرق `brand-*` معرّفة في `src/app/globals.css`؛ عدّلها لتطابق التصميم المعتمد.
- الواجهات مبنية بمكونات **Base UI** (`@base-ui/react`) مخصصة بـ Tailwind، واتجاه الصفحة RTL.

## الإنتاج

```bash
npm run build && npm start
```

- اضبط `APP_URL` على الرابط العام (يُستخدم في `callback_url` لمُيسر) و `SESSION_SECRET` بقيمة عشوائية طويلة.
- SQLite مناسب للبداية؛ للتحويل إلى PostgreSQL غيّر `provider` في `prisma/schema.prisma` و `DATABASE_URL`.

## بنية المشروع

```
prisma/schema.prisma        نموذج البيانات
src/proxy.ts                إخفاء لوحة التحكم خلف ADMIN_PATH
src/lib/authentica.ts       إرسال والتحقق من رمز الجوال
src/lib/moyasar.ts          جلب الدفعات من مُيسر
src/lib/orders.ts           إنشاء الطلب وحجز السلع وتأكيد الدفع
src/lib/images.ts           ضغط الصور
src/actions/                Server Actions (الدخول، السلع، السلة، الدفع، الإدارة)
src/app/(site)/             صفحات المنصة
src/app/cp/                 لوحة التحكم (تُخدم عبر ADMIN_PATH فقط)
src/app/api/webhooks/moyasar  Webhook مُيسر
```
