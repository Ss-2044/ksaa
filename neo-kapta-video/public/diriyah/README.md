# صور الدرعية الحقيقية

ضع الصور هنا بهذه الأسماء (JPG، يفضّل 1920×1080 أو أكبر)، ثم أعد التصدير (`npm run render`).
كل صورة تُستخدم تلقائياً في كل المقاطع التي تعرض هذا المكان بدل المشهد المرسوم:

| الملف | المكان | يظهر في |
|---|---|---|
| `turaif-sunset.jpg` | حي الطريف (لقطة واسعة، يفضّل وقت الغروب) | جاء الوقت · الأبواب · البطاقات · العدسة |
| `turaif-wall.jpg` | جدار أو برج طيني من قريب | جاء الوقت · البطاقات · العدسة |
| `bujairi-night.jpg` | البجيري ليلاً (إضاءة دافئة) | جاء الوقت · البطاقات (البطاقة الأخيرة) |
| `bujairi-terrace.jpg` | مطلّ/ساحات البجيري | الأبواب · البطاقات · العدسة |
| `wadi-hanifa.jpg` | وادي حنيفة والنخيل | جاء الوقت · الأبواب · البطاقات · العدسة |

تأكد أن لديكم حق استخدام الصور (صوركم الخاصة، أو من شركة الدرعية، أو صور مرخّصة مع ذكر المصدر).
