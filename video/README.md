# فيديو ترويجي — Remotion (30 ثانية)

فيديو عمودي 1080×1920 بنص عربي وإنجليزي، بألوان الشعار (فضي/أبيض) مع خلفية خضراء متدرجة متحركة.
Vertical 1080×1920, 30 fps, 30 s — bilingual (AR/EN), logo-colored, animated gradient background.

## التشغيل / Usage

```bash
npm install
npm run studio   # معاينة وتعديل / preview in Remotion Studio
npm run render   # تصدير / export -> out/promo.mp4
```

The rendered file is also committed as `promo.mp4`.

If Remotion can't download its own Chrome, point it to a local one:
`REMOTION_BROWSER=/path/to/chrome npm run render`

## السيناريو / Timeline (`src/timeline.json`)

| Time | Scene |
|---|---|
| 0–2s | تقليب الـ iPad (صورة) مع تقريب سينمائي / iPad push-in |
| 2–11.5s | مونتاج سريع داخل الـ iPad: إعلان، خريطة، أرقام وبيانات، سوشال ميديا، مطعم، منتج، شخص يشاهد إعلان، حملة إعلانية، Graph يرتفع، فكرة على ورقة |
| 11.5–18s | VO: "Every idea starts somewhere." — كل فكرة تبدأ من مكانٍ ما |
| 18–21s | لقطة الوجه / face close-up |
| 21–26.7s | VO: "But not every idea knows where to go." — لكن ليست كل فكرة تعرف إلى أين تذهب |
| 26.7–30s | الشعار + "حيث تجد الأفكار طريقها" |

Change durations in `src/timeline.json`, then run `npm run music` so the sound effects stay in sync.

## Assets (`public/`)

- `logo.png`, `ipad.webp`, `cabin.png` — from the repo / provided images
- `product.mp4`, `watch.mp4`, `campaign.mp4`, `face.mp4` — short shots trimmed from the provided `.mov`
- `vo1.mp3`, `vo2.mp3` — placeholder text-to-speech voice over. Replace with a real recording (same file names) and re-render.
- `music.wav` — generated by `scripts/make-music.mjs` (pad, swipe whooshes, riser, hits)
