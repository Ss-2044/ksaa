# NEO CAPTA — «رحلة فكرة» (Remotion, 40 ثانية)

الفيديو الرئيسي هو composition اسمه `Journey`: مقاسه 1080×1920، 30 fps، ومعه موسيقى وضربات ومؤثرات صوتية متزامنة مع الحركة.
الملف الجاهز موجود في `neocapta-journey.mp4`.

```bash
npm install
npm run music    # يولّد public/journey-music.wav من src/journey/timeline.json
npm run render   # تصدير -> out/neocapta-journey.mp4
```

| الوقت | المشهد |
|---|---|
| 0–4s | خط يرسم لمبة وتضيء — «كل فكرة تبدأ من مكانٍ ما» |
| 4–13.3s | بطاقة صعود للفكرة ووجهتها «؟؟؟» — «لكن ليست كل فكرة تعرف إلى أين تذهب»، ثم ختم NEO CAPTA يحدد الوجهة: SUCCESS / النجاح — «نحن نمنح كل فكرة وجهتها» |
| 13.3–19.3s | لوحة مغادرة بحروف تتقلّب (Split-flap): الاستراتيجية، الهوية، المحتوى، الحملات، النمو |
| 19.3–28.3s | طيارة تمشي على خريطة وتوقف عند كل خدمة وتطلع بطاقتها |
| 28.3–34.6s | منظر من شباك الطيارة: الستارة ترتفع والمدينة بالليل تتنوّر حول شعار NEO CAPTA — «وصلت فكرتك… والكل يشوفها» |
| 34.6–40s | طيارة تعبر الشاشة، ثم شعار NEO CAPTA و«لكل فكرة وجهة» |

إذا غيّرت أي توقيت في `src/journey/timeline.json`، شغّل `npm run music` بعده عشان الصوت يبقى متزامن.

## التصميم الثالث: «جواز سفر الأفكار» — `Passport` (38 ثانية)

تصميم فاتح بأسلوب المجلات: خلفية ورق، خطوط كبيرة، ومساحات بالأزرق الملكي. الملف الجاهز في `neocapta-passport.mp4`.

```bash
npm run music:passport   # يولّد public/passport-music.wav من src/passport/timeline.json
npm run render:passport
```

| الوقت | المشهد |
|---|---|
| 0–3.7s | «فكرة / IDEA» بخط ضخم ← «Every idea starts somewhere» |
| 3.7–17.3s | جواز السفر: الغلاف ← صفحة البيانات (الحامل: فكرتك) ← 5 أختام للخدمات ← ختم «اكتملت الرحلة» |
| 17.3–27.3s | صالة الوصول: كل خدمة تهبط وتطلع نتيجتها (STR، BRD، CNT، CMP، GRW) |
| 27.3–32.3s | لوحة إرشاد في المطار: «أهلاً بفكرتك في وجهتها» |
| 32.3–38s | الشعار داخل ختم دائري يدور + «لكل فكرة وجهة» |

أدوات الصوت المشتركة بين الموسيقى موجودة في `scripts/synth.mjs`.

## نسخ سابقة

فيديو عمودي 1080×1920، 30 fps، **بدون صوت** — الكلام نصوص متحركة عربي/إنجليزي بألوان شعار نيو كابتا
(أزرق ملكي، فضي، أسود مع نقاط halftone).

## التشغيل / Usage

```bash
npm install
npm run studio   # معاينة وتعديل
npm run render   # تصدير -> out/neocapta-promo.mp4
```

If Remotion can't download Chrome: `REMOTION_BROWSER=/path/to/chrome npm run render`.

| 36–40s | شعار نيو كابتا + "لكل فكرة وجهة / Every idea, a direction" |

## Assets (`public/`)

- `neocapta-logo.png` — الشعار مفرّغ من الخلفية

لتبديل شعار الشريك: عدّل `PartnerEmblem` في `src/scenes/PartnershipScene.tsx` (حالياً رمز عام، ليس شعار جهة حقيقية).

## نسخة ريف (لقطات ذكاء اصطناعي) — `AIPromo`

- `ai-kit/PROMPTS.md`: وصف كل لقطة وطريقة توليدها.
- `ai-kit/magazine-cover.png` و `ai-kit/magazine-spread.png`: مراجع المجلة. تعيد توليدها بـ `npm run magazine`.
- حط المقاطع المولّدة في `public/shots/` بأسماء `shot01.mp4` … `shot09.mp4`، وأي لقطة ناقصة تطلع مكانها شاشة مؤقتة.
- ترتيب اللقطات ومدتها والنصوص في `src/ai/shots.ts`.
- للتصدير: `npm run render:ai`
