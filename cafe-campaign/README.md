# حملة «أول رشفة» — افتتاح كافيه

**الفكرة:** الافتتاح هو «أول رشفة» للمدينة من الكافيه. نبني الحماس بالريحة قبل الطعم، ونخلي أول زيارة لحظة يصوّرها الناس وينشرونها.

**الألوان:** إسبريسو `#1A0F0A` · محمّص `#3B2418` · كريمة `#EAD9C2` · حليب `#F7F0E6` · كراميل `#C8884A`
**العناصر:** كوب من فوق مع رسمة قلب على الحليب، حبوب بن، وبخار.

## قبل النشر
- استبدل `CAFÉ` والكوب المؤقت بشعار الكافيه واسمه الحقيقي (أعلى `designs.py`)، وعبّئ التاريخ والموقع والحساب.
- `python3 designs.py` يعيد توليد التصاميم في `out/`.
